🎓 The Ultimate Viva Guide (50 Questions)

Smart Campus Placement Portal | Final Year Project Defense
⚠️ Memorize the "Critical" questions. Read the "Technical" ones twice.
🔹 1. Project Overview & Scope
Critical
Q1
What is your project about? (The Elevator Pitch)
"It is an AI-Integrated Smart Placement Portal. Unlike traditional portals that only store data, ours actively bridges the skill gap using Gemini 1.5 Pro to analyze resumes, recommend courses, and conduct voice-based mock interviews for students."
Q2
What are the main modules?
"We have three core modules: Student (Apply, AI Analysis, Mock Test), TPO (Manage Drives, Analytics), and HOD (Verify Students, Dept Analytics)."
Q3
What makes your project 'Smart' or 'Innovative'?
"Three things: 1. Context-Aware AI that acts as different personas (Interviewer/Counselor). 2. Auto-Healing API mechanism that switches keys if Google blocks one. 3. Voice Interaction using Web Speech API."
Q4
Is this a live project?
"It is designed as a production-grade prototype. It utilizes industry standards like connection pooling and parameterized queries, ready for cloud deployment on platforms like Render."
Q5
What methodology did you follow?
"We followed the **Agile Methodology**. We built the core Database first, then the Auth system, then iterated on the AI features based on testing feedback."
🔹 2. Tech Stack & Architecture
Critical
Q6
Why Flask and not Django/Node.js?
"Django is too heavy/opinionated. I needed Flask's flexibility to write custom AI wrappers and manage asynchronous API calls without the overhead of a large framework."
Q7
Explain the MVC Architecture.
"Model: database.py (Data Layer). View: templates/*.html (User Interface). Controller: app.py (Business Logic & Routing)."
Q8
Why MySQL? Why not MongoDB?
"Placement data is highly relational (Students -> Applications -> Drives). SQL ensures Data Integrity and ACID compliance, which is critical for official academic records. NoSQL is better for unstructured data, which is only a small part of our app."
Q9
What frontend library did you use?
"I used Bootstrap 5 for responsive layout and Vanilla JavaScript for logic. For the 3D effect, I used Three.js, and for charts, I used Chart.js."
Q10
How does the application run? (Entry Point)
"The entry point is app.py. When executed, it initializes the Flask server, connects to the DB pool, and starts listening on port 5000."
🔹 3. AI & Logic (The Engine)
Technical
Q11
How exactly does the AI analyze a resume?
"We extract text using PyPDF2. Then we construct a **Prompt** containing the text + Job Description + Strict JSON Output rules. We send this to Gemini Pro, which returns a structured JSON assessing the match."
Critical
Q12
What happens if the AI Hallucinates?
"We limit hallucination by using a Low Temperature (0.1 - 0.3) in our API calls for analytical tasks. We also instruct the AI to 'Only output attributes found in the text' in the System Prompt."
Q13
Explain the "Key Rotation" logic.
"In gemini_ai.py, I have a list of API keys. If a request returns a '429 Quota Exceeded' error, the rotate_key() function instantaneously switches the global client to the next key and retries the request."
Q14
What is "Persona-Based Prompting"?
"It's when we tell the AI 'You are a Strict HR' or 'You are a Helpful Career Guide'. This changes the tone and strictness of the response. See PLACEMENT_AI_SYSTEM_PROMPT in code."
Q15
Does it support local LLMs?
"Code-wise, yes. The SafeGenerativeModel class can be extended to point to a local Ollama endpoint, but for performance on this laptop, we use Cloud APIs."
Q16
How is the Mock Interview stored?
"We store the conversation context in the Session memory during the interview. Once finished, we can choose to save the final feedback to the database."
Q17
How do you parse complex PDFs?
"We use PyPDF2. For multi-column resumes, we rely on the LLM's natural language understanding to figure out the flow of text, rather than writing complex regex parsing logic."
Q18
What is the "Skill Gap"?
"It is the set difference: {Job Required Skills} minus {Resume Skills}. The AI identifies this and then maps the missing skills to recommended courses."
🔹 4. Database & Backend
Technical
Q19
Explain Connection Pooling.
"Opening a DB connection is expensive (handshake, auth). QueuePool keeps a set of open connections (e.g., 10). When a user requests data, we give them an existing connection. This increases throughput by 10x."
Q20
How do you handle Passwords?
"We use werkzeug.security.generate_password_hash with SHA-256. We NEVER store plain text passwords. We salt and hash them."
Q21
What are the key tables?
"Users, Drives, Applications, Resumes, Notifications, CodingSubmissions. The central table is Applications."
Q22
How do you prevent duplicate applications?
"We query the database: `SELECT id FROM applications WHERE student_id=X AND drive_id=Y`. If a record exists, we block the request."
Q23
How are files stored?
"Files are stored in the filesystem under static/uploads/. The Database only stores the File Path string. Storing blobs in DB makes backups huge and slow."
Q24
Explain the "Notifications" logic.
"When a TPO posts a drive, we trigger an insert into the notifications table for all eligible students. The frontend polls this table."
Q25
What is "ACID"?
"Atomicity, Consistency, Isolation, Durability. Our MySQL transactions ensure that if an application fails halfway, no partial data is saved."
🔹 5. Security & Deployment
Critical
Q26
What is SQL Injection? How did you fix it?
"It's when a user inputs SQL code (e.g., `' OR 1=1`) to hack the DB. I fixed it by using Parameterized Queries (%s) which treats input strictly as data, not executable code."
Q27
What is XSS (Cross Site Scripting)?
"Injecting malicious JS into pages. Flask's Jinja2 engine automatically Escapes all variables `{{ var }}`, converting scripts to harmless text strings."
Q28
Where are your API Keys?
"In a .env file. They are loaded at runtime using `os.getenv`. They are NOT committed to GitHub."
Q29
What if the server restarts? (Session)
"We use client-side signed cookies for sessions. So if the server restarts, the user stays logged in as long as the SECRET_KEY remains the same."
Q30
How would you deploy this to AWS?
"I would use an EC2 instance or Elastic Beanstalk. I'd wrap the app in Gunicorn (Production WSGI server) behind an Nginx reverse proxy."
🔹 6. Frontend & User Experience
Q31
How does the Voice Chat work?
"Web Speech API. The browser handles the heavy lifting of converting Speech-to-Text. We just get the text string and send it to our backend."
Q32
Is the site responsive?
"Yes, we used Bootstrap Grid system (col-md-*, col-sm-*). It works on mobile, tablet, and desktop."
Q33
Why Glassmorphism?
"It's a modern UI trend (frosted glass effect). It gives a premium feel suitable for a 'Smart' AI application."
Q34
How do charts work?
"Chart.js. We fetch JSON data from the backend (Flask) and render it into HTML Canvas elements."
Q35
Explain the "Three.js" background.
"It renders a particle wave in a standard HTML5 Canvas using WebGL. It creates a 'Digital Mainframe' aesthetic."
🔹 7. Scenario Based (Tricky)
Critical
Q36
"Your project looks simple. What was the hardest part?"
"Handling the Inconsistency of LLM outputs. Sometimes the JSON was broken. I had to write Regex parsers to 'clean' the AI response before using it."
Q37
"If I delete a Student, what happens to their Applications?"
"In a real system, we'd use Cascade Delete. Currently, we do a Soft Delete (mark as inactive) to preserve history."
Q38
"Why not use a Ready-made ATS?"
"Commercial ATS systems are expensive and don't offer Student-Centric Coaching features like Skill Gap Analysis. Ours is a Learning Platform, not just a Filtering tool."
Q39
"How accurate is the Analysis?"
"It uses semantic matching (meaning-based), so it's approx 85-90% accurate compared to detailed human review, but 100x faster."
Q40
"Can TPO see private student chats?"
"No. Mentorship chats are private. TPO only sees aggregated analytics (e.g., 'Common missing skill: Python')."
Q41
"What if internet connection is lost?"
"The basic database features (Login, View Drives) assume connectivity. The AI features will fail gracefully with a 'Connection Error' message."
